# 🌈 小小彩虹牧场 (Little Rainbow Ranch)

一款给 **5–8 岁小朋友** 的温柔牧场游戏：照顾小动物、进鸡舍捡鸡蛋、种菜、挤牛奶、做料理、完成客人的订单、装扮自己的小主人公。

**没有失败、没有倒计时惩罚、没有抽奖、没有任何付费内容。**

在线试玩 👉 **https://hydrogx.github.io/rainbow-ranch/**

| 系统 | 说明 |
| --- | --- |
| 🏡 牧场主场景 | 2400×1900 的大牧场：小屋、鸡舍、牛棚、羊圈、菜地、水井、仓库、烹饪小屋、商店、客人接待区，白天黑夜与天气实时变化 |

| 🌦️ 天气与昼夜 | 晴天 / 阴天 / 雨天（渐变过渡，雨天自动浇水、出现水洼）；白天 / 傍晚 / 晚上（星空、月亮、萤火虫、灯光） |

## 🎮 怎么玩

| 操作 | 说明 |
| --- | --- |
| 方向键 / WASD | 走路 |
| 鼠标点击地面 | 自己走过去（小朋友最喜欢的操作） |
| 空格 / 点击物体 | 和旁边的东西互动 |
| 底部快捷栏 | 切换 🖐️手 / 🌾饲料 / 💧水壶 / 🌱种子 / 🪣奶桶 / 🧺篮子 / 🌷装饰 |
| 玩到一半想睡觉？ | 点击小屋「回家睡一觉」直接到第二天早上 |
| Esc | 关闭当前面板 |

> 顶部状态栏显示时间、天气、金币、彩虹星星、订单与背包入口。

**小提示**：把「手」换成「饲料」再去点动物就是喂食；换成「水壶」就是洗澡；换成「奶桶」点奶牛会进入挤奶场景；换成「篮子」可以收获农产品。

## 🧪 自动化验收

项目自带一个无头浏览器验收脚本：它会真的打开构建产物，跑一遍完整剧本（选角色 → 逛牧场 → 喂动物 → 买东西 → 换装 → 摆装饰 → 捡鸡蛋 → 种菜收获 → 做料理 → 交付订单 → 切天气昼夜 → 刷新页面验证存档），
把每一步截图到 `verification/`，并报告任何 `console` 错误、未捕获异常和 404。

```bash
npm run verify          # 构建 + 完整剧本
npm run verify:quick    # 只检查能否正常启动
```

脚本使用系统已安装的 Chrome（`puppeteer-core`，不下载浏览器）。

## 🛠️ 技术栈

- **Vite + TypeScript**：构建与类型安全
- **Phaser 3**：游戏世界（场景、物理、补间、粒子）
- **DOM + 内联 SVG**：界面（状态栏、快捷栏、商店 / 厨房 / 订单 / 换装面板）
- **GitHub Actions + GitHub Pages**：自动构建与发布

### 资源完全自包含

**所有美术都是 SVG 矢量文件，构建时以字符串形式打包进 JS，运行时用 Canvas 栅格化成贴图；音效全部由 WebAudio 实时合成。**

也就是说：不请求任何外部图片、字体、CDN 或音频文件，**离线也能完整游玩**，部署到 GitHub Pages 不需要任何额外配置。

```
src/assets/            ← 美术源文件（SVG，唯一真实来源）
public/assets/         ← 由 npm run sync-assets 从 src/assets 复制，方便美术直接替换
```

替换美术只需要改 `src/assets/` 下的 SVG，然后 `npm run art`（重新生成 + 同步）。

## 📝 与 PRD 的对应说明

- 第 4.6 / 4.7 / 7 节描述的「烹饪小屋 / 客人订单 / 商店」按 PRD 建议使用 SVG 图标 + CSS 动画实现，界面层放在 DOM 面板里（而不是独立的 Phaser 场景），这样文字更清晰、触摸目标更大、拖拽材料更顺手，对 5–8 岁小朋友更友好。
- PRD 食谱表中的「牛奶 = 牛奶」在实现里变成了可玩的「温牛奶 = 牛奶」，其余 7 个食谱与 PRD 完全一致。
- 彩虹星星**只累积、不消耗**，用来解锁新食谱和高级装饰，避免小朋友"失去星星"的挫败感。
